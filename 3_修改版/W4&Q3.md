**Weakness / Question 原文：** The paper should report AVE-Agent’s practical overhead, including average latency, tool-call and retry counts, and inference or API cost per edited clip. Reporting controlled comparisons and efficiency would strengthen the work.

**中文翻译：** 论文应报告 AVE-Agent 的实际运行开销，包括平均延迟、工具调用次数、重试次数，以及每个编辑视频的推理成本或 API 成本。报告受控比较和效率分析将进一步增强这项工作。

**Q4: AVE-Agent 的延迟、工具调用、重试次数和 API 成本是多少？**

**A4:** 感谢审稿人对实际开销的关注。

我们补充统计了 AVE-Agent 在固定 Kling O3 Pro 后端下的端到端延迟、工具调用、Evaluator 调用、重试频率和 API 成本，并与直接调用同一后端进行受控比较。该设置确保额外开销来自 Agent 的规划、评估和局部修正流程，而不是后端模型差异。

| 指标                 |           Direct Kling O3 Pro |     AVE-Agent (Kling) |          增加开销 |
| -------------------- | ----------------------------: | --------------------: | ----------------: |
| 平均延迟             |                    约 7.7 min | **约 12.0 min** | +4.3 min，约 +56% |
| API 成本             | US$1.68 |**约 US$1.90** |     +US$0.22，约 +13% |                   |
| 外部工具调用         |                             1 |         **3.4** |              +2.4 |
| Evaluator 调用       |                             0 |         **3.6** |              +3.6 |
| Retry                |                             0 |        **1.36** |             +1.36 |
| 触发 refinement 比例 |                            0% |      **53.60%** |                — |

AVE-Agent 平均生成多个具有依赖关系的规划子任务，并仅在检测到执行或跨模态一致性问题时触发 refinement。约**53.6%** 的任务需要进一步修正，平均仅进行**1.36 次 retry**，说明系统并非对所有样本进行固定次数的高成本重复生成，而是采用按需计算策略，将额外预算集中在确实存在问题的任务上。

与直接调用 Kling O3 Pro 相比，AVE-Agent 的平均 API 成本仅增加约**13%**。这是因为超过 90% 的总费用仍来自视频编辑后端，规划、Evaluator 和反馈生成本身只占较小部分。换言之，Agent 的主要代价体现在增加约 4.3 分钟的串行延迟，而不是大幅增加 API 费用。结合受控消融中 Full AVE-Agent 相比 No Evaluation/Retry 和 Naive Planner 的显著提升，这些额外调用并非无差别堆叠计算，而是通过结构化规划、错误定位和定向修正有效转化为编辑质量收益。

按完整 190 条指令外推，AVE-Agent 的串行总运行时间约为**38 小时**，API 总成本约为**US$361**；相较直接 Kling，额外增加约**13.6 小时和 US$42**。这一结果表明，AVE-Agent 在获得更强指令执行、跨模态协调和整体真实感的同时，保持了可控的实际成本。系统的主要代价是串行 refinement 带来的等待时间，而不是规划与评估调用造成的大幅费用增长。
