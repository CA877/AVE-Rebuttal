## Reviewer 2FXf

**Weakness 原文：** Reproducibility concerns. The evaluation pipeline depends on specific LLM/MLLM versions for checklist generation and judging. These are closed-weight models. The paper should specify exact versions, inference settings, and ideally provide an open-source alternative.

**中文翻译：** 评测流程存在复现性方面的疑虑。该流程依赖特定版本的 LLM/MLLM 来生成检查清单并进行判断，而这些模型均为闭源权重模型。论文应明确说明具体版本和推理设置，并最好提供一个开源替代方案。

**Q4: 如何保证闭源 LLM/MLLM 评测流程的可复现性，并提供开源替代？**

**A4:** 感谢审稿人对评测复现性的关注。当前实验中，**checklist 生成与主观评测均使用 Gemini 3.1 Pro**。我们会完整提供模型版本、推理参数、prompt 模板、视频帧与音频采样方式、输出解析规则和重试策略，同时公开生成后的 checklist 与缓存判断结果，便于直接复核论文中的评测过程。

该发布方式将“复核已报告结果”与“使用当前 judge 重新运行评测”分开：前者依赖可版本化的 checklist、逐项判断和聚合脚本，因而不会因 API 后续更新而改变；后者则可通过替换 judge 检验方法排序对评测后端的敏感性。

为检验结论是否依赖特定闭源 judge，我们进一步将主观评测模型替换为开源的**Qwen3-Omni-30B-A3B-Instruct**，并在完整评测集上重新评测。除 judge 模型外，输入样本、checklist、评分维度和聚合方式均保持一致，因此该比较只考察 judge 替换带来的影响。

| Model                      | Instruction Following ↑ | Fidelity Preserving ↑ | Realism / AVQ ↑ |
| -------------------------- | -----------------------: | ---------------------: | ---------------: |
| Wan2.7                     |                    71.17 |                  85.00 |            54.32 |
| LTX2                       |                    63.33 |                  75.83 |            51.29 |
| **AVE-Agent (Ours)** |          **80.83** |        **87.50** |  **69.10** |

在 Qwen3-Omni 评测下，AVE-Agent 在 IF、Fidelity 和 Realism/AVQ 三个维度上均保持第一，三种方法的相对排序与 Gemini 3.1 Pro 一致。从表中可以看出，Qwen3-Omni 给出的绝对分数整体更高，反映出其对局部编辑失败和细粒度保真问题的判定相对宽松，但这一尺度差异没有改变方法间的比较结论。

复现性可分为两个层面。公开生成后的 checklist、逐项判断缓存和聚合规则，使论文中的分数能够在不重新调用闭源 API 的情况下被审计；开源 judge 实验则说明，在完整评测集上替换评测模型后，核心排序仍然保持一致。前者保证已有结果可核查，后者降低重新运行评测对单一闭源模型的依赖。

两种复现路径因此形成互补：固定中间产物保证报告分数可精确追溯，开源 judge 的排序一致性则表明主要模型比较不由 Gemini 的特定分数尺度决定。
