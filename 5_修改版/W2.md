### （1）Content Difficulty 与 Instruction Length Level 的定义

**Content Difficulty** 是依据标注规则给出的离散等级，并非由某个连续分数按阈值切分。critic model 先按以下规则给出标签，再由人工检查其与指令内容是否一致。分层综合考虑五个因素：源视频结构、编辑目标明确程度、编辑作用范围、所需音频处理，以及音视频耦合关系。

* **Easy**：局部、单目标且边界明确的编辑，不涉及复杂时序变化或跨模态推断。
* **Medium**：包含一个主要复杂因素，例如需要音视频联动、较大范围修改或更复杂的目标定位。
* **Hard**：同时包含多个复杂因素，或涉及多镜头、全局场景变换、时序操作、跨模态因果推断或音源分离。

该分层衡量任务涉及的结构、模态和时序约束，而非某个单一视觉属性。

图 4 中的 **Instruction Length Level** 同样是人工核验的离散标签，实际表示指令的**语义负荷**，而非按字数或 token 数设置阈值。

* **Easy**：只包含一个直接且显式的编辑意图，目标对象、操作和目标模态均已明确给出。
* **Hard**：需要理解复合意图、上下文约束、隐式跨模态后果，或对象与声源之间的对应关系。

该定义能够区分“文字较长但操作简单”与“文字较短但包含隐式跨模态推理”的指令，避免 token 数掩盖真正的语义复杂度。为避免术语歧义，我们会将图中标签改为 **Instruction Semantic Complexity**。

换名后的标签与实际标注对象一致，也直接消除了“Instruction Length 是否按 token 阈值划分”的歧义。我们会在图注中同时给出上述操作性定义，使读者无需从曲线反推分组标准。

### （2）视频时长增加时 AVE-Agent 的表现

随视频时长增加，Wan2.7 和 LTX2 的分数均明显下降，AVE-Agent 则保持稳定并呈现小幅上升。这一对比支持的核心结论是 **AVE-Agent 对较长视频具有更强的编辑稳健性**。这里的分析对象是时长带来的额外时序与跨模态负担，而非将“更长”视为一种更容易的任务条件。

该稳健性与三个针对长时序编辑的设计相一致：

1. **结构化视频分析**首先将长视频压缩为包含场景、镜头、音频和语音信息的结构化描述，避免后续模块直接依赖未经组织的长时序输入。
2. **Subtask DAG** 将全局编辑指令拆分为具有明确依赖关系和评价标准的局部子任务，使复杂长视频编辑不再依赖单次端到端生成。
3. **Evaluator-driven correction** 能够识别长视频中更容易出现的时序漂移、跨镜头不一致和音视频错位，并通过局部重新混音、重生成或重新规划进行针对性修正。

这三个机制都针对长视频新增的困难：结构化描述减少长上下文信息丢失，DAG 避免把多阶段编辑压缩为一次生成，Evaluator 则在错误出现后提供局部修正机会。因此，它们可以解释 AVE-Agent 为何没有像端到端基线一样随时长增加而明显下降。

因此，Figure 4 的时长趋势应读作一个相对稳健性结果：端到端基线在更长输入上出现退化，AVE-Agent 通过结构化上下文、显式任务依赖和反馈驱动修正保持了表现。该发现说明 Agent 设计把长视频带来的额外复杂性转化为可分解、可检查和可定向修正的子问题。
